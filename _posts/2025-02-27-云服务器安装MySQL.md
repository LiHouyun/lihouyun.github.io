### 3.6 MySQL 权限设置
```sql
-- 创建用户
CREATE USER 'root'@'%' IDENTIFIED BY '[密码]';

-- 授予权限
GRANT ALL PRIVILEGES ON [数据库名].* TO 'root'@'%';

-- 刷新权限
FLUSH PRIVILEGES;
```

### 3.7 3306 端口的设置，可以监听 IPV4
确保 MySQL 配置文件（通常位于 /etc/my.cnf）中的 bind-address 参数设置为 0.0.0.0，以允许远程连接：
```sh
bind-address = 0.0.0.0
```
重启 MySQL 服务使生效
```sh
sudo systemctl restart mysqld
```
检查
```sh
[root@localhost Documents]# sudo netstat -tulnp | grep 3306
tcp        0      0 0.0.0.0:3306            0.0.0.0:*               LISTEN      108253/mysqld 
```

### 3.8 配置阿里云安全组
阿里云服务器默认会阻止外部访问 MySQL 的端口（默认是 `3306`），需要在安全组中放行该端口。

1. 登录阿里云控制台。
2. 进入 **ECS 实例管理**。
3. 找到你的服务器实例，点击 **安全组**。
4. 在安全组规则中，添加一条入方向规则：
   - 协议类型：`MySQL (3306)`
   - 授权对象：`0.0.0.0/0`（允许所有 IP 访问）或指定你的客户端 IP 地址。
5. 保存规则。

```sh
# 报错
C:\Users>mysql -u root -p -h [服务器 IP] --ssl-mode=DISABLED
Enter password: ******
ERROR 2061 (HY000): Authentication plugin 'caching_sha2_password' reported error: Authentication requires secure connection.

# 解决方案
# 登录到 MySQL 服务器：
mysql -u root -p
# 修改用户认证插件：
ALTER USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY '你的密码';
FLUSH PRIVILEGES;
# 退出 MySQL：
EXIT;
# 重新尝试连接：
mysql -u root -p -h [服务器 IP] --ssl-mode=DISABLED
```
